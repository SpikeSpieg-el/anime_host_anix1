# 🏆 Самая эффективная колода на 35 provision

## Формула расчёта силы карты

```
basePower = HP/8 + ATK×0.5 + DEF×0.3 + SPD×0.3 + LUCK×0.2
```

**Приоритет статов:** ATK > DEF ≈ SPD > LUCK > HP

## 🔥 ТОП-3 комбинации на 35 очков

### Вариант A: «omnipotent+mix» — вес=34, 8 карт
```
1x omnipotent   (prov=11)
1x legendary    (prov=7)
1x epic         (prov=5)
1x super_rare   (prov=4)
1x rare         (prov=3)
1x uncommon     (prov=2)
```

- **Базовая сила**: ~1020
- **Синергии**: rarity_spectrum(+5) = +40
- **ИТОГО**: ~**1060**

## Система синергий (максимум +25 на карту)

| Синергия | Условие | Бонус |
|----------|---------|-------|
| **Братство** | 2+ карты из одного аниме | +4 за каждую после первой |
| **Гармония ролей** | Все 3 роли в колоде | +8 |
| **Спектр редкостей** | 5+ разных редкостей | +5 |
| **Лёгкая поступь** | Вес колоды ≤ 28 | +5 |
| **Элита** | 4+ карт epic и выше | +6 |
| **Специализация** | 4+ карт одной роли | +6 этой роли, -3 остальным |

## ✅ ФИНАЛЬНАЯ РЕКОМЕНДАЦИЯ

### Лучший вариант: B (divine+ancient+2epic)

**Состав:**
```
1x divine       (9)   — ядро колоды, максимальная сила
1x ancient      (8)   — вторая топовая карта
2x epic         (10)  — основа для синергии elite
2x rare         (6)   — заполнение
1x uncommon     (2)   — дешёвая карта
1x trash        (0)   — filler
```

**Настройки:**
- **Лидер**: divine карта (максимальная базовая сила)
- **Формация**: balance (+5/+5/+10 всем ролям)

**Для максимизации синергий:**
- Все карты из **одного аниме** → brotherhood (+12-16 дополнительно!)
- Минимум **5 разных редкостей** → rarity_spectrum (+5)
- Минимум **4 карт epic+** → elite (+6)

**Ожидаемая итоговая сила:** ~**1100-1150** с полными синергиями
