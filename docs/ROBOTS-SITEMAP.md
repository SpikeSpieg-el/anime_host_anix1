# robots.txt: почему так, а не иначе

Дата: 2026-11-06. Файл — `public/robots.txt`. Сам файл держим коротким: он
публичный, и раньше 60% его объёма занимали комментарии о внутренней кухне
(схема токенов плеера, путь к исходнику, история «страйков»). Это готовая
шпаргалка для правообладателей и конкурентов, а не документация.

## Ключевые решения

### Единая группа `User-agent: *`

Отдельной группы `Googlebot` / `YandexBot` нет намеренно. По спецификации
группы с конкретным user-agent и глобальная группа не объединяются: отдельная
группа должна повторять ВСЕ правила, иначе краулер потеряет запреты на
`/admin/`, `/bookmarks` и т.д. Глобальная группа уже даёт роботам всё нужное:
обход страниц, CSS/JS-бандлы и превью через `/api/thumbnail-proxy`.

Источник: developers.google.com/crawling/docs/robots-txt/robots-txt-spec.

### `/_next/` НЕ закрыт

`Disallow: /_next/` ломал рендер: Googlebot не мог скачать CSS/JS-бандлы и
оптимизированные картинки, видел неоформленную разметку и получал штраф и по
mobile-friendly, и по Core Web Vitals. Google прямо просит не закрывать CSS/JS.

### `/embed/` закрыт для всех

Ссылки вида `/embed/<token>` одноразовые (короткий срок жизни токена), отдают
`X-Robots-Tag: noindex` и 404 роботам. Обход — расход краулингового бюджета.
`VideoObject.embedUrl` на `/watch` намеренно не ссылается сюда: раньше там был
`/embed/{id}` без токена, который всегда отдавал 404 и ломал разметку видео
(подробности — `docs/SEO-WATCH-AUDIT.md`).

### Allow для картинок перед общим `Disallow: /api/`

`/api/thumbnail-proxy` — источник `thumbnailUrl` в `VideoObject`. Без доступа
к нему Google отдаёт причину «Доступ к уменьшенным изображениям запрещен
файлом robots.txt». `/api/image-proxy` — обложки новостей для `og:image`
(Shikimori и MAL запрещают хотлинк). При конфликте правил робот применяет
наименее ограничительное, поэтому `Allow` идёт первым.

### `genre` и `year` не в `Clean-param`

Эти параметры меняют содержимое: у фасетных страниц `self-canonical`. Когда
`genre` стоял в `Clean-param`, Яндекс срезал параметр и видел только голый
`/catalog` — жанровых страниц для него просто не существовало.

### `www`

`www.weeb-x.com` отдаёт 308 на apex (middleware). Подробности и проверка —
`docs/WWW-REDIRECT.md`.
