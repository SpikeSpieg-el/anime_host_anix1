Современная веб-платформа для просмотра аниме с красивым интерфейсом и мощным функционалом. Построена на Next.js 16 с использованием TypeScript и современных UI-компонентов.

## 🌟 Основные возможности

- **Каталог аниме** - Обширная база данных с фильтрацией по жанрам, годам, статусам и рейтингам
- **Просмотр в хорошем качестве** - Интеграция с Kodik API для стриминга
- **Умные рекомендации** - Персональные рекомендации на основе истории просмотров
- **Закладки и история** - Сохранение любимых тайтлов и отслеживание прогресса
- **Поиск с подсказками** - Быстрый поиск по названию аниме с историей запросов
- **Адаптивный дизайн** - Идеально работает на всех устройствах
- **Темная тема** - Комфортный просмотр в любое время суток
- **Уведомления о сериях** - Отслеживание выхода новых серий
- **Аутентификация пользователей** - Профили и персонализация

## 🛠 Технологический стек

- **Frontend**: Next.js 16, React 19, TypeScript
- **UI**: Tailwind CSS 4.1, shadcn/ui, Radix UI
- **База данных**: Supabase
- **API**: Shikimori API, Kodik API, Anilist API
- **Состояние**: React Hooks, Cookies для хранения данных
- **Стили**: Tailwind CSS с кастомными анимациями
- **Аналитика**: Vercel Analytics

## 📦 Установка и запуск

### Требования
- Node.js 18+
- npm или pnpm

### Установка зависимостей
```bash
npm install
# или
pnpm install
```

### Переменные окружения
Создайте файл `.env.local` в корне проекта:
```env
KODIK_API_TOKEN=your_kodik_api_token_here
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url_here
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key_here
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key_here
```

### Запуск разработки
```bash
npm run dev
# или
pnpm dev
```

Приложение будет доступно по адресу `http://localhost:80`

### Сборка для продакшена
```bash
npm run build
npm start
```

## 🔌 API Интеграция

### Shikimori API
Основной источник данных о аниме:
- Информация о тайтлах
- Рейтинги и отзывы
- Франшизы и связанные аниме
- Новости и анонсы

### Kodik API
Стриминг видео:
- Плеер для просмотра новых, старых серий
- Списки серий и озвучек
- Качество видео

### Anilist API
Дополнительный источник изображений:
- Постеры и обложки
- Фоновые изображения

### Supabase
База данных и аутентификация:
- Профили пользователей
- История просмотров
- Закладки
- Уведомления о новых сериях

## 🎨 Особенности реализации

### Генеративные постеры
Уникальная система генерации SVG-постеров для аниме без обложек:
- 4 различных стиля оформления
- Автоматическая адаптация размера текста
- Стабильный хеш для одного названия

### Оптимизация производительности
- Параллельные запросы к API
- Кэширование данных
- Ленивая загрузка изображений
- Оптимизированные запросы для предотвращения rate limiting

### UI/UX особенности
- Плавные анимации и переходы
- Адаптивная сетка карточек
- Интуитивная навигация
- Поддержка клавиатуры
- Поиск с автодополнением
- Умные уведомления
